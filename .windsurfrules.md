# Project Rules for Browser-to-ComfyUI Extension

## Architecture Overview

Chrome extension for saving prompts from websites and sending to ComfyUI for image generation.

```
src/
├── background.ts    # Service worker: context menu, shortcuts, messages
├── popup.ts         # Popup UI: history, settings, generation controls
├── content.ts       # Content script: auto-detect prompts on domains
├── types.ts         # TypeScript interfaces and constants
├── utils.ts         # Shared utilities: storage, API, workflow builder
└── workflows/       # ComfyUI workflow JSON templates
    ├── qwen-t2i-base.json     # Base T2I workflow
    └── qwen-t2i-upscale.json  # Upscale nodes
```

## Build & Tooling

- `npm run build` - Production build to `dist/`
- `npm run dev` - Watch mode for development
- Vite bundles TypeScript to separate JS files per `vite.config.ts`

## Coding Standards

- TypeScript with strict typing, no `any`
- camelCase for variables/functions, PascalCase for types/interfaces
- Modules: `types.ts` for interfaces, `utils.ts` for shared functions
- Mock Chrome APIs with jest-chrome for testing

## ComfyUI Workflow System

Workflows are JSON templates in `src/workflows/`:

- **Static changes**: Edit JSON files directly, run `npm run build`
- **Dynamic parameters**: Update `buildComfyUIWorkflow()` in `utils.ts`
- **New UI controls**: Add to `ComfyUIPayload` in `types.ts`, then `popup.ts`

See `docs/workflow-update-guide.md` for detailed instructions.

### Key Workflow Nodes

| Node | Purpose |
|------|---------|
| 3 | KSampler (seed, steps, cfg) |
| 105 | Negative prompt |
| 110 | Positive prompt |
| 113 | Aspect ratio, megapixel |
| 79 | SaveImage (regular) |
| 81 | SaveImage (upscaled) |

## Adding Features

1. **New settings**: Add to `ComfyUISettings` in `types.ts`, update `DEFAULT_SETTINGS`
2. **New workflow params**: Add to `ComfyUIPayload`, update `buildComfyUIWorkflow()`
3. **New UI controls**: Add HTML to `popup.html`, bind in `PopupApp` class
4. **New workflows**: Create JSON in `src/workflows/`, import in `utils.ts`

## Storage

- `chrome.storage.sync` - Settings (synced across devices)
- `chrome.storage.local` - Prompt history, auto-detect domains

## Prompt Detection

- Manual: Context menu "Save as Prompt", keyboard shortcut Ctrl+Shift+P
- Auto: Content script with configurable markers (`[PROMPT START]`...`[PROMPT END]`)

## Commits

Small, focused commits with descriptive messages (e.g., "Add upscale toggle to popup UI").
